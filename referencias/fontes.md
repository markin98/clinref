# Registro de fontes

Toda ficha (`farmacos/`, `procedimentos/`, `escalas/`) cita fontes por **chave**, nunca
reescreve a referência completa — ex.: `**Fontes:** surviving-sepsis, stahl`.

Quando uma fonte for atualizada (nova edição, nova diretriz), atualizar a linha aqui e
marcar `⚠` na coluna Situação — um grep pela chave acha toda ficha que cita a versão
antiga e precisa de revisão. Este registro nasceu portando a bibliografia que já existia,
compartilhada, nos três guias HTML (seção "Referências" de cada um) — não é uma lista nova.
